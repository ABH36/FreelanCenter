## 2. What was built

- `packages/blocks`: `registry.ts` (`createRegistry`, `getBlock`, `listBlocks`), `blocks/*.tsx` (one file per section block), `chrome.tsx`, `render.tsx` (`renderSections`, `renderSection`, `expandNode`), `parts.tsx` (`CtaButton`, `Picture`, `Rich`), `cta.ts` (`resolveCta`, `resolveHref`, `mapHref`), `icons.tsx`, `strings.ts` (English and Hindi interface strings), `blocks.css`, `error-boundary.tsx`.
- Every block publishes: label, description, variants, strict props schema (from `@platform/schema`), editor field metadata (a test fails if a prop is missing or its required flag differs from the schema), valid default content per variant.
- Styling is one static stylesheet (`@platform/blocks/blocks.css`) on the S2 variables: no inline style anywhere (strict CSP), no per-tenant CSS.
- Schema (`packages/schema`) changes made because the blocks exposed gaps: section anchors (`#contact`, `/#contact`, `/about#team`) for navigation and `scroll` CTAs, with a dangling-anchor check; `business.language` (`en` | `hi`, default `en`).

## 4. Security, privacy, failure paths

- Tenant text is only ever a React child (escaped); a test renders quotes, ampersands and entity lookalikes and checks they come out escaped. Rich text is data nodes. Props are re-validated with the block schema before every render, so a stored config that no longer validates is never rendered (stage `props`).
- All hrefs go through `resolveHref`/`resolveCta` (paths, anchors, `https:`, `tel:`, `mailto:` only); external links get `target="_blank" rel="noopener noreferrer"` and a screen-reader note. Property test: 3,000 mutated configs; every one the schema accepts renders without an exception and without a block error; no `<script>`, `<iframe>`, inline handler or inline style; every `href` starts with `/`, `#`, `https://`, `tel:` or `mailto:`.
- Error reports carry type, variant, section id and a safe summary: never props or tenant text (tested).
- No network, no storage, no third-party request in any block (source scan). Images use only the pre-generated widths through `ctx.assetUrl` (ADR-009); until assets exist (P3) an accessible placeholder is rendered.
