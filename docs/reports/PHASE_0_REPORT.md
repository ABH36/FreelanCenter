```

                ├──imports (source)────►├─ packages/schema, db, blocks, ai, jobs, providers  [placeholders]
apps/sites     ─┘                       └─ packages/config (tsconfig + ESLint rules)

   schema/blocks/ui ✗ db/jobs/ai/providers/@prisma/* (lint)
DEVELOPMENT_PLAN.md ≡ SRS.md (byte-identical mirror, CI-checked)
```

**Spike B schema (disposable, `spikes/spike-b-rls-pooling/db/init.sql`) - schema/RLS list:** tables `workspace`, `project`, `lead`, `domain`, all `ENABLE` + `FORCE ROW LEVEL SECURITY`; policy `tenant_isolation` (for `app_user`) using `current_workspace()`; narrow policies for `svc_definer`: `definer_read` on `domain` and `project`, `definer_insert` and `definer_returning` on `lead`; functions `current_workspace()`, `resolve_host()`, `insert_lead()` (both `SECURITY DEFINER`, `search_path` fixed); roles `migrator`, `app_user`, `app_public`, `svc_definer` - **none superuser, none BYPASSRLS**; `migrator` is a member of `svc_definer` `WITH INHERIT FALSE, SET TRUE`; composite FKs `(workspace_id, project_id)`.

## 7. Performance and cost (measured versus targets)

- **NFR targets** (LCP, TTFB, Lighthouse, API p95, AI latency): **not measurable in Phase 0** (no pages, API or AI calls).
- **Spike B (local Docker, 300 sequential `findMany take 5`):** with the tenant wrapper p50 8.05 ms / p95 42.9 ms; without p50 2.48 ms / p95 5.1 ms. Burst of 300 concurrent with Prisma defaults: **156 failed**; tuned: 400 operations, 0 errors, 0 leaks.
- **Builds:** dashboard and sites each compile in ~47-49 s cold.
- **Spike E (measured, one photo):** WebP 4-width set 150.7 KB / 0.6 s; AVIF 110.7 KB / 5.4 s; JPEG 221.1 KB / 0.5 s.
- **Spike E (model, assumptions labelled):** 25,000 sites, 1,500 visits/site/month: Vercel optimizer $2,404-$5,091/mo; R2 + pre-generated ~$20/mo; Cloudflare on-demand ~$579/mo. The Vercel bom1 Fast Data Transfer rate was not read (range used).
