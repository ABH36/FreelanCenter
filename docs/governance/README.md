# Documentation Governance

This folder contains the rules that keep all feature documentation coherent and truthful.

1. [DOCUMENTATION_INDEX.md](DOCUMENTATION_INDEX.md) — authoritative reading order, hierarchy and task matrix.
2. [CROSS_MODULE_CONTRACTS.md](CROSS_MODULE_CONTRACTS.md) — invariants shared by every module: tenancy, state, events, idempotency, privacy and release compatibility.
3. [DOCUMENTATION_GAP_REGISTER.md](DOCUMENTATION_GAP_REGISTER.md) — unresolved real-world proofs/decisions, owners and exact closure evidence.
4. [OWNER_INPUT_CHECKLIST.md](OWNER_INPUT_CHECKLIST.md) — exact external inputs and evidence required from the Owner by phase.
5. [DEVELOPMENT_ENVIRONMENT_POLICY.md](DEVELOPMENT_ENVIRONMENT_POLICY.md) — approved no-cost local/preview workflow and production-domain gate.

Read the index before implementation; read the gap register before a phase or vendor-dependent task.
